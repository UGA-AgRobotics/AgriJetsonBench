Historical provenance

The Nano 15 W battery run configuration records the engine path. The current
file matches the archived build metadata SHA-256, 98db667629cb3776c3f204085e99986d4b8923a94a805f4a59d9b01beeb75aab.
The earlier metadata inspection of those bytes returned 190
layer names with LAYER_NAMES_ONLY verbosity. Its internal precision assignments
remain unresolved.

TensorRT's plan header reader reports 10.3.0.30. The original cache header is
TRT-100300-EntropyCalibration2. These records and the installed 10.3.0.30 builder
and parser establish the compatible stack. The archived sidecar records 10.4.0
and is preserved with the conflicting label. The version command logs are included.

Build and cache controls

The separate C++ helper retains the original static input 1 × 3 × 640 × 640,
batch size 1 and 4096 MiB workspace. INT8 and FP16 are enabled, and TF32 uses
the TensorRT default. The input was the exact
historically parsed ONNX file, whose SHA-256 equals the original source ONNX.
The helper uses kDETAILED profiling and an EntropyCalibration2 calibrator that
only returns bytes from a read-only copy of the original cache. Its batch and
cache-write callbacks terminate the process at entry.

TensorRT logged 2 reads of the 34,723-byte copied cache and use of its
calibration scales. The build completed with zero batch requests and zero
cache-write requests. The before/after SHA-256 values match for the historical
engine, both ONNX paths, the original cache and the original builder sources.
The copied cache also retained its original SHA-256.

The build log contains TensorRT's internal tactic selection timings. The
Inspector read the saved plan without an execution context. The diagnostic used
the board's active 25 W mode. The historical battery experiment used 15 W.
