MobileNetV3 Training_Cluster package asset note

- This package does not require a mandatory external pretrained checkpoint.
- Default behavior: train from scratch unless `model.init_checkpoint` is set in the config.
- The default implementation path uses `torchvision` segmentation models with a MobileNetV3 backbone.
- Default variant: `lraspp_mobilenet_v3_large`.
- Optional alternate variant: `deeplabv3_mobilenet_v3_large`.
- Automatic remote weight download is intentionally disabled for reproducible offline Training_Cluster compute-node runs.
- If you later want to warm-start from a local checkpoint, place the file inside the package root or `assets/` and update `config/segmentation_mobilenetv3_train_lock.yaml`.
