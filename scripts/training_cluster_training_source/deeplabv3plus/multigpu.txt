DeepLabV3++ rerun notes for the stable single-node `4 x L4` setup

Main chained command:

```bash
cd ${TRAINING_CLUSTER_HOME}/jetson_edge_ai_benchmark/stage2_deeplabv3plus_training_cluster_4L4
bash scripts/submit_optuna.sh --partition gpu_p --nodes 1 --gres gpu:L4:4 --cpus 32 --mem 96G --time 168:00:00
```

Using package defaults is also valid:

```bash
cd ${TRAINING_CLUSTER_HOME}/jetson_edge_ai_benchmark/stage2_deeplabv3plus_training_cluster_4L4
bash scripts/submit_optuna.sh
```

This job:
- runs Optuna first
- then, if Optuna finishes successfully, continues to full training in the same job

Run only full training:

```bash
bash scripts/submit_deeplabv3plus.sh --mode full --partition gpu_p --nodes 1 --gres gpu:L4:4 --cpus 32 --mem 96G --time 168:00:00
```

Run only the smoke test:

```bash
bash scripts/submit_deeplabv3plus.sh --mode smoke --partition gpu_p --nodes 1 --gres gpu:L4:4 --cpus 32 --mem 96G --time 12:00:00
```

Important notes:
- No new environment is created. The package reuses the shared segmentation environment.
- `submit_optuna.sh` continues the previous Optuna study because it uses `load_if_exists=True`.
- If you want a completely fresh study, archive or remove the previous Optuna runtime first.
